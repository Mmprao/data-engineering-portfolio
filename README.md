# Data Engineering Portfolio

A collection of hands-on projects demonstrating practical data engineering skills using Python, SQL, PySpark, and Azure-oriented data pipeline patterns.

> These are independent portfolio projects built for learning and demonstration. They are not presented as production deployments or work completed for an employer.

## Projects

| Project | Tools | What it demonstrates |
|---|---|---|
| [01 - Python ETL Pipeline](projects/01-python-etl-pipeline/README.md) | Python, CSV | Extract, clean, validate, and load structured data |
| [02 - SQL Analytics](projects/02-sql-analytics/README.md) | SQL | Joins, aggregations, CTEs, and window functions |
| [03 - PySpark Data Processing](projects/03-pyspark-data-processing/README.md) | Python, PySpark | DataFrame transformations and data quality checks |
| [04 - Azure Medallion Pipeline](projects/04-azure-medallion-pipeline/README.md) | Azure Data Factory concepts, ADLS Gen2, Python, SQL | Bronze / Silver / Gold architecture and an end-to-end batch pipeline design |

## Skills represented

- ETL / ELT fundamentals and repeatable pipeline design
- Data cleaning, type conversion, validation, and duplicate handling
- SQL joins, aggregations, CTEs, and window functions
- PySpark DataFrame transformations
- Azure Data Factory and ADLS Gen2 pipeline concepts
- Bronze, Silver, Gold, and Quarantine data layers
- Documentation, reproducibility, and Git version control

## Getting started

Each project has its own README with setup instructions and example commands. The Python examples can run locally. The Azure project includes a local simulation and cloud configuration guidance; no Azure deployment is implied.
