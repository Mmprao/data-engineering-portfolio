# Data Engineering Portfolio

A collection of hands-on projects demonstrating practical data engineering skills using Python, SQL, PySpark, and cloud-oriented data pipeline patterns.

> These are independent portfolio projects built for learning and demonstration. They are not presented as production deployments or work completed for an employer.

## Projects

| Project | Tools | What it demonstrates |
|---|---|---|
| [01 - Python ETL Pipeline](projects/01-python-etl-pipeline/README.md) | Python, CSV, SQL concepts | Extract, clean, validate, and load structured data |
| [02 - SQL Analytics](projects/02-sql-analytics/README.md) | SQL | Business questions, joins, aggregations, and window functions |
| [03 - PySpark Data Processing](projects/03-pyspark-data-processing/README.md) | Python, PySpark | Distributed transformations and data quality checks |

## Skills represented

- ETL / ELT fundamentals and repeatable pipeline design
- Data cleaning, type conversion, validation, and duplicate handling
- SQL joins, aggregations, CTEs, and window functions
- PySpark DataFrame transformations
- Layered data organization inspired by Bronze, Silver, and Gold architecture
- Documentation, reproducibility, and Git version control

## Getting started

Each project has its own README with setup instructions and example commands. Most examples are designed to run locally. Cloud services such as Azure Data Factory and Azure Data Lake Storage are discussed as architecture extensions; no Azure deployment is implied.
