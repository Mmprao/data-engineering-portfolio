# 02 - SQL Analytics

A compact SQL practice project built around a fictional retail order dataset. The queries answer common operational and business questions.

## Topics

- Filtering and sorting
- INNER and LEFT JOIN patterns
- GROUP BY and aggregate functions
- Common table expressions (CTEs)
- Window functions such as ROW_NUMBER and running totals
- Basic data quality checks

## Files

- `schema.sql` creates the example tables.
- `analysis_queries.sql` contains example analysis and validation queries.

## Run

Run `schema.sql` and then `analysis_queries.sql` in a SQL environment that supports standard SQL and window functions. Minor syntax adjustments may be needed for a specific database engine.

The data is fictional and included for demonstration only.
